# <p align="center">ezmpv

A calm and simple media player for Android, built on top of libmpv through [libmpv-android](https://github.com/jarnedemeulemeester/libmpv-android).

![GitHub Release](https://img.shields.io/github/v/release/chardoncs/ezmpv)

> [!NOTE]
>
> Under development. It will reach v1.0 when the features are complete.

## Features

- libmpv
- Play audio and video
- Background playback
- Mini player
- User playlists
- Browse local files
- Audio-only mode
- Casino (true random) mode for playing tracks
